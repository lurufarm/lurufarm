02. className과 classList

    HTML 요소의 class 어트리뷰트는 DOM에서 className과 classList라는 두 가지 프로퍼티로 관리할 수 있다.
    className 프로퍼티는 문자열로 클래스 전체의 값을 읽거나 설정할 수 있다.
    className에 문자열을 할당하면 기존 클래스를 덮어쓴다.

    classList 프로퍼티는 class 어트리뷰트를 관리하는 객체인 DOMTokenList를 반환한다.
    classList 프로퍼티는 개별 클래스를 추가, 제거, 토글, 확인할 수 있다.
